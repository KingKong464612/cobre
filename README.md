# Cobre

Sintetizador polifónico para el navegador: teclas en pantalla, mapeo del teclado, formas de onda, filtro, envolvente, octava, volumen, osciloscopio y medidor de nivel. El audio solo empieza después de un gesto (encender o tocar una tecla).

## Hecho con IA

Este proyecto está hecho con IA. El código, la interfaz y los textos se generaron con ayuda de inteligencia artificial (Grok). Revísalo antes de reutilizarlo.

## Teclas

- Blancas: A S D F G H J K L y las dos teclas a su derecha
- Negras: W E T Y U O P
- Z baja la octava, X la sube
